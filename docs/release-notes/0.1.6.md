## Highlights
- **New application icon** everywhere: exe, windows, taskbar, Start menu, Add/Remove Programs and About.
- **The DarkCipher look of WhisperDesk and ServerManagement**: same palette, fonts, type ramp and corners. Plus presets (High Contrast, Graphite, Teal, Light, Follow Windows) and extensive, safe customisation.
- **Catalogue**: install, update, repair and uninstall Claude Code, Codex and Ollama through winget, always with a full plan and your approval.
- **Templates**: 13 validated templates connect agent, runtime, model and project. Only compatible templates are offered; every check names its fix. Configuration is deterministic and fingerprinted.
- **One download and installation queue**: an item is Ready only after its post-install test passes.
- **Configuration transactions, stack diagnosis and repair, full end-to-end verification**, and a supported-configuration matrix that records exactly what was proven.
- **SDK 1.1** for extension-contributed templates, catalogue entries, model sources, rules, health checks and settings.

## Honest status
- Nothing was installed by the catalogue while this release was tested. winget, the source lookups and the install plans were verified live; the install, update and uninstall steps are covered by automated tests with a scripted executor.
- No configuration is labelled **Supported and Verified** for 0.1.6 yet: neither Claude Code nor Codex is installed on the build PC. See `SUPPORTED-CONFIGURATIONS.md`.
- Custom and extension-contributed agent tools can be registered and validated, but sessions with them are Planned.
- The updater is still OFF (no release signing key exists).
- A real `msiexec /i` install has still not been run on this PC; the MSI was validated (ICE) and its extracted payload passed the self-test.

## Upgrading from 0.1.5
Install the MSI over 0.1.5 (major upgrade). Settings, stacks and projects are kept. The first start adds an appearance
settings file with the defaults; the existing interface layout is unchanged unless you customise it.
