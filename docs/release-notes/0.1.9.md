# DarkCipher AgentControl 0.1.9 — release notes (2026-10-20)

**Unsigned build.** No code-signing certificate exists. Verify files against `SHA256SUMS.txt` before running them.
Windows SmartScreen will warn about the MSI and the exe.

## What is in this folder

| File | What |
|---|---|
| `DarkCipherAgentControl-0.1.9-win-x64.msi` | Per-machine installer: `C:\Program Files\DarkCipher Systems\AgentControl` (one administrator approval), Start-menu shortcuts (normal and Safe Mode) |

## What changed
- **Much more to install** from the catalogue, all with winget, per-user, no administrator rights:
  - LM Studio, llama.cpp, Jan and llamafile.
  - GitHub Copilot CLI, OpenCode, Crush, Kilo CLI and Amp CLI.
  - Git, Node.js LTS, Python 3.13, uv, ripgrep, fd, jq and the GitHub CLI.
  - The gateways built into those runtimes; installing one installs its runtime.
- **Install from the page you are on:**
  - Agents, Services and Models all have Install or Download buttons.
  - Model buttons show progress live and offer Resume or Retry for unfinished downloads.
  - Extensions has a Gallery of seven bundled, data-only extensions.
- **Right-click menus everywhere.** Crowded menus are grouped into submenus.

## Honest status
- The new tools are **Catalogue only**: install, update, detect and remove work, but stacks and sessions still use Claude Code or Codex with Ollama.
- Every new package was checked live against the winget source (per-user installer, detection, plan). None of them was actually installed by this app during testing.
- Bundled gallery extensions are not separately signed. They are trusted as part of the app's install folder.
- Supported configurations are unchanged: Codex + llama3.2 is Supported and Verified; Claude Code + llama3.2 failed validation (model too small).
- The updater is still OFF (no release signing key exists).

## Upgrading from 0.1.8
Install the MSI over 0.1.8 (major upgrade). Settings, stacks, projects and installed extensions are kept.
