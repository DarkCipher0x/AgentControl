# DarkCipher AgentControl 0.1.5 — release notes (2026-10-19)

**Unsigned build.** No code-signing certificate exists. Verify files against `SHA256SUMS.txt` before running them.
Windows SmartScreen will warn about the MSI and the exe.

## What is in this folder

| File | What |
|---|---|
| `DarkCipherAgentControl-0.1.5-win-x64.msi` | Per-machine installer. Installs to `C:\Program Files\DarkCipher Systems\AgentControl` (one administrator approval), plus Start-menu shortcuts (normal and Safe Mode). |
| `DarkCipherAgentControl-0.1.5-win-x64.zip` | Portable, self-contained app (no .NET install needed) |
| `DarkCipher.AgentControl.Sdk.1.0.0.nupkg` | Extension SDK (contracts only) |
| `dcx-ext-0.1.5-win-x64.zip` | Extension tooling. Needs the .NET 8 runtime. |
| `samples/*.dcxext` | Two data-only and two code sample extensions |
| `DarkCipherAgentControl-0.1.5-docs.zip` | Full documentation |
| `sbom.cdx.json`, `THIRD-PARTY-LICENCES.txt` | CycloneDX 1.5 SBOM and licence list |
| `BUILD-INFO.txt` | Build date, SDK, test, self-test and validation results |
| `SHA256SUMS.txt` | SHA-256 of every file above |

## Changes since 0.1.4
- **Installer fixed.** Earlier MSIs were marked per-user but targeted `C:\Program Files\DarkCipher AgentControl`, so the install stopped with "insufficient privileges". It is now a per-machine MSI in `C:\Program Files\DarkCipher Systems\AgentControl`, matching the other DarkCipher Systems apps. The app itself still never runs elevated. **0.1.4 is superseded.**
- `tools\setup.ps1` (from 0.1.4) checks prerequisites and fetches all build dependencies.
- No application code changed. The updater is still OFF (no release signing key exists).
