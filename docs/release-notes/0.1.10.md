# DarkCipher AgentControl 0.1.10 — release notes (2026-10-21)

**The first public release.** AgentControl is now open source under the MIT licence, at
[github.com/DarkCipher0x/AgentControl](https://github.com/DarkCipher0x/AgentControl). It is a Windows control plane for
agentic AI coding: it sets up local models and coding agents, tests what really works on your PC, and runs agent
sessions behind central security controls.

**Unsigned build.** No code-signing certificate exists, so Windows SmartScreen will warn about the MSI and the exe.
Check every file against `SHA256SUMS.txt` first.

## What it does

- **Quick Setup.** It scans your hardware and recommends a stack and model. It installs the missing runtime and agent
  with winget (per-user, no administrator rights, each after you approve its plan) and starts Ollama if needed. Then it
  downloads the model and tests it.
- **Catalogue.**
  - Agents: Claude Code and Codex CLI, plus GitHub Copilot CLI, OpenCode, Crush, Kilo and Amp.
  - Runtimes: Ollama, LM Studio, llama.cpp, Jan and llamafile, with the gateways built into them.
  - Supporting tools: Git, Node.js, Python, uv, ripgrep, fd, jq and the GitHub CLI.
  - Every package is pinned and installs per-user. An install only counts once its post-install test passes.
- **Compatibility you can trust.** Models are tested on your PC (text, instructions, code, JSON schema, tool calls),
  and stacks are verified end to end in a throwaway project. Only then is a configuration labelled
  **Supported and Verified**.
- **Templates** connect agent, runtime, model and project, with deterministic, fingerprinted configuration and
  transactional, rollback-safe configuration changes.
- **One download queue** for models, Hugging Face GGUF imports and tool installs, with resume and retry.
- **Extensions:**
  - SDK 1.1.
  - A bundled gallery of data-only template and model packs.
  - Code extensions behind Development Mode, labelled as not isolated.
- **Security:**
  - Protected folders and a secure process executor (no shell, validated paths, job objects).
  - A deny-by-default network policy.
  - Secrets only in Windows Credential Manager.
  - A tamper-evident audit log.

## New in 0.1.10

- The source is public (MIT).
- Every release now comes from one automated pipeline. The public repository, the GitHub Release and the website all
  come from a single privacy-scanned source archive, built from an explicit allowlist and checked by gitleaks. A kill
  switch (`DCX_PUBLISH_OFF=1`) stops publishing at once. See `docs/RELEASE.md`.

## Honest status

- **Supported and Verified** (on the build PC, exact versions only): Codex CLI 0.161.0 + Ollama 0.40.6 + llama3.2,
  Code Review template.
- Claude Code through a local gateway is **Experimental**: Anthropic doesn't support it, and small models fail its
  end-to-end test.
- Tools marked **Catalogue only** can be installed, updated, detected and removed, but no stack uses them yet.
- The updater is off: no release signing key exists.

## Upgrading

Install the MSI over any earlier version (major upgrade). Settings, stacks, projects and extensions are kept.
