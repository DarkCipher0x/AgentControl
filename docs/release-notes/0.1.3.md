# DarkCipher AgentControl 0.1.3 — release notes (2026-10-18)

**Unsigned build.** No code-signing certificate exists. Verify files against `SHA256SUMS.txt` before running them.
Windows SmartScreen will warn about the MSI and the exe.

## What is in this folder

| File | What |
|---|---|
| `DarkCipherAgentControl-0.1.3-win-x64.msi` | Per-user installer (no admin rights). Installs to `%LOCALAPPDATA%\Programs\DarkCipher AgentControl`, plus Start-menu shortcuts (normal and Safe Mode). |
| `DarkCipherAgentControl-0.1.3-win-x64.zip` | Portable, self-contained app (no .NET install needed) |
| `DarkCipher.AgentControl.Sdk.1.0.0.nupkg` | Extension SDK (contracts only) |
| `dcx-ext-0.1.3-win-x64.zip` | Extension tooling (`new`, `validate`, `analyse`, `check-compat`, `pack`). Needs the .NET 8 runtime. |
| `samples/*.dcxext` | Two data-only and two code sample extensions |
| `DarkCipherAgentControl-0.1.3-docs.zip` | Full documentation: user, admin, security, privacy, architecture, ADRs, developer, SDK, extensions, troubleshooting, recovery, testing, release, report |
| `sbom.cdx.json`, `THIRD-PARTY-LICENCES.txt` | CycloneDX 1.5 SBOM and licence list (NuGet packages and .NET runtime packs) |
| `BUILD-INFO.txt` | Build date, SDK, test, self-test and validation results |
| `SHA256SUMS.txt` | SHA-256 of every file above (`sha256sum -c` format) |

## Changes since 0.1.1
- 0.1.3 is the same code as 0.1.2. Its documentation was scrubbed of the development PC user path, and the build now enforces this. 0.1.2 is superseded.
- **Fixed**: the Quick Setup sample project was blocked as an agent working folder (the data-folder protection was too broad). Sensitive app folders stay closed to agents and extensions.
- **Claude Code local mode**: passes the real context window to Claude Code.
- **Verified for real on the development PC**: Claude Code 2.1.296 launched by the app's own plan through the secure executor in a disposable project (headless). It answered via Ollama gpt-oss-64k on loopback, and the process tree started and stopped cleanly.
- **Self-test**: now includes a Quick Setup dry run (31 checks).
- **Packaging**: MSI, portable zip, SDK package, tool, samples, docs bundle, SBOM, checksums.

## Status of major features
- **Verified**:
  - Central security services.
  - Hardware detection.
  - Recommendations.
  - Ollama runtime and compatibility suite.
  - Claude Code launch through the local gateway (headless).
  - Extension platform and SDK.
  - Packaging and checksums.
- **Experimental**: Claude Code with a local model (Anthropic does not support it; the model is not Claude).
- **Implemented, not fully verified**:
  - Interactive (windowed) agent sessions launched from the UI.
  - Full Quick Setup run that downloads a model.
  - Codex local mode (Codex is not installed on the development PC).
  - Live Hugging Face search and import.
  - A real (non-extract) MSI install and uninstall.
- **Planned**:
  - Out-of-process extension isolation.
  - Other runtimes (LM Studio, llama.cpp, vLLM, LocalAI).
  - NPU inference.
  - Benchmark screen.
  - Signed releases and updater.
